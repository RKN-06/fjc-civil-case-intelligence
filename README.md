# FJC Civil Case Intelligence (Streamlit)

Predicts how a U.S. federal civil case ends (Dismissed, Judgment, Settled, Statistical closing, Transferred) and how many days it takes, using models trained on the FJC Integrated Database (cv23 extract).

Pages: Outcome Predictor, Duration Predictor, Case Segments (K-Means) and Model Laboratory (leaderboards and diagnostics).

Run locally:

```
pip install -r requirements.txt
streamlit run Home.py
```

On Streamlit Community Cloud, set the main file to `Home.py` and choose Python 3.12.

The `artifacts/` folder is generated by `scripts/build_streamlit_bundle.py` in the main project: the fitted scaler, encoder and PCA, the saved models (each under 100 MB) and the result reports. Nothing is retrained by the app.
